# गणित यात्रा — Class 6

This directory contains the modular Mathematics layer for the learning platform.

## Current NCERT scope
The current Class 6 NCERT mathematics textbook is **Ganita Prakash**. The 2026–27 reprint lists 8 chapters:

1. Large Numbers Around Us
2. Arithmetic Expressions
3. A Peek Beyond the Point
4. Expressions using Letter-Numbers
5. Parallel and Intersecting Lines
6. Number Play
7. A Tale of Three Intersecting Lines
8. Working with Fractions

Reference: NCERT Ganita Prakash 2026–27.

## Planned learner flow
Concept → Worked Example → Try Yourself → Hint → Step Check → Mistake Analysis → Challenge → Revision

## Maths design rules
- Never reveal the final answer before the learner has had a chance to try.
- Show intermediate steps for multi-step problems.
- Distinguish arithmetic error, sign error, place-value error, operation-choice error and reasoning error where possible.
- Keep notation readable on mobile screens.
- Use objective tests with transparent marking: correct +1, incorrect 0, unanswered 0, no negative marking unless a future test explicitly declares another scheme.
- Keep each chapter in its own file so content can be improved independently.
